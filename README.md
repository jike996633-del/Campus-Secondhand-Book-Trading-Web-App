# Campus Second-hand Book Trading API

## Project Introduction
A back-end API for second-hand book trading based on Node.js + Express, supporting functions such as user registration/login, book publishing/management/search, and storing data in memory (data is cleared after service restart).

## Technology Stack
- Framework: Node.js + Express
- Authentication: JWT + bcrypt
- Cross-domain: cors
- Development Tool: nodemon (Automatic restart)
